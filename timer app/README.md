## ✨ Features

- ⚡ **Live Real-time Countdown**: Days, Hours, Minutes, and Seconds for each subject synchronized with Nepal Kathmandu Time (UTC+5:45).
- 🎯 **Hero Spotlight**: Prominently highlights the immediate next exam (`ENSH 151: Engineering Mathematics II`).
- 🌓 **Dark & Light Mode**: Smooth theme toggling with preference memory (`localStorage`).
- 🔀 **Multiple Views**:
  - **Cards Grid View**: Detailed visual cards with individual timers and focus buttons.
  - **Table View**: Compact overview of dates, codes, and live remaining time.
  - **Timeline View**: Visual chronological flow of the exam preparation journey.
- 🧘 **Zen / Focus Mode**: Distraction-free full-screen countdown for deep study sessions (press `Esc` to exit).
- 📅 **Calendar Sync (.ics Export)**: One-click export to Google Calendar, Apple Calendar, or Outlook with 24-hour reminder alarms at 1:00 PM NPT.
- 🔔 **Web Notifications**: Optional browser notification reminders.
- 📱 **Fully Responsive**: Optimized for desktops, tablets, and smartphones.
